# Security Policy

## Supported Versions

Currently, only the latest release of the `main` branch is actively supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| `< 1.0` | :x:                |

## Reporting a Vulnerability

We take the security of APIS seriously. If you discover a security vulnerability within APIS, please do not disclose it publicly or post it as a GitHub issue. 

Instead, please send an e-mail to our security team at `security@example.com`. We will evaluate the vulnerability and issue a patch as quickly as possible. We will endeavor to respond to your report within 48 hours.

Please include:
* A description of the vulnerability.
* Steps to reproduce the issue.
* Potential impact.
* Any known mitigations.

Thank you for helping keep APIS and the AI infrastructure ecosystem safe.
